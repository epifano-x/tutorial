# Experimentos de ordenação em C

Este repositório reúne quatro etapas de exercícios de ordenação e medição de resultados. Cada pasta contém o código-fonte do ordenador (`ordenador.c`), um gerador de arquivos em C e uma planilha `Resultados.xlsx`. Algumas pastas também preservam os arquivos de entrada usados nos ensaios.

| Etapa | Algoritmos presentes em `ordenador.c` |
| --- | --- |
| [T1](T1_Bruno_Roglin/) | Bubble Sort e Insertion Sort |
| [T2](T2_Bruno_Roglin/) | Bubble, Insertion, Shell, Selection e Quick Sort |
| [T3](T3_Bruno_Roglin/) | Bubble, Insertion, Shell, Selection, Quick e Merge Sort |
| [T4](T4_Bruno_Roglin/) | Algoritmos da T3, além de Heap e Radix Sort |

Os programas usam `windows.h` e `conio.h`, então o código é direcionado ao console do Windows. Os arquivos `.exe` e `.o` guardados nas pastas são artefatos das atividades; para estudar ou modificar os algoritmos, consulte os arquivos `.c`. Os conjuntos de entrada incluem sequências aleatórias, ordenadas e invertidas, com tamanhos indicados nos nomes dos arquivos. As planilhas registram os resultados de cada etapa.

Este é um registro acadêmico dos experimentos, não uma biblioteca de ordenação pronta para integração em outros projetos. Não foram alterados os códigos, dados ou resultados originais ao adicionar este índice.
